Bootstrapping the Tauri 2 shell (TK-008) hit a real local-only failure: `npm run tauri build` (via `make check-desktop`) failed with `error running bundle_dmg.sh: failed to run .../bundle_dmg.sh` when a prior `tauri build` invocation had left a temporary read-write DMG volume mounted under `/Volumes/dmg.*` (visible via `hdiutil info`, image path `src-tauri/target/release/bundle/macos/rw.<pid>.corytm_0.1.0_aarch64.dmg`). Detaching the stale volume (`hdiutil detach /Volumes/dmg.* -force`) and removing the leftover `rw.*.dmg` file made the next build succeed immediately, unchanged otherwise. Re-running `cargo tauri build`/`npm run tauri build` back-to-back on the same macOS machine before a previous run's DMG bundling step has fully unmounted is the likely trigger.

This is local-dev-loop only — GitHub Actions runners are always clean, so it cannot recur in CI and needs no CI-side fix. Worth checking `hdiutil info | grep -i corytm` and `/Volumes` first if a future session sees `bundle_dmg.sh` fail on this machine.
