# Roadmap — Stable

Canonical entries for every capability whose first rollout, on any surface, is Stable. See `README.md` in this directory for reading rules, mutation/authority semantics, Commitment (Committed/Conditional) semantics, and Flags.

Stable is furthest from current work, so its entries stay terse and their eventual implementation shape is the least settled — but they remain at approximately the same Feature/capability granularity as `alpha.md` and `beta.md`, not collapsed into broader objective-level statements. Only detailed scope/acceptance criteria are deferred rolling-wave (`docs/project/plan.md`), exactly as for every other phase's terse entries, refined only as Beta nears its own exit.
