# EP-001 — Engineering Foundation

Status: done
Milestone: MS-001

## Objective

Establish Corytm's minimum viable engineering foundation — Python, frontend, and native toolchains, plus a unified developer/quality interface — sufficient for disciplined implementation to begin.

## Scope / Out of scope

In scope: Python project foundation; React/TypeScript frontend foundation; native C++ (Tracktion Engine + JUCE) build/test foundation; a unified canonical developer/quality interface exposing a Task-level quality gate and a full-repository quality gate. Source-tree paths are materialized only as each foundation genuinely needs them — no upfront skeleton pass.

Out of scope: any product feature; real UI design/design-system implementation; real Python↔C++ protocol content; CI; harness validation.

## Acceptance criteria

A uv-managed Python project, a TypeScript-strict frontend project, and a native build all exist and pass their own checks. One root Makefile invokes all of them. No product/domain functionality is implemented anywhere.

## Dependencies

None.
