# EP-002 — Continuous Integration & Platform Validation

Status: done
Milestone: MS-001

## Objective

Prove the engineering foundation holds outside one local machine, by having CI automatically invoke Corytm's canonical quality interface across both supported desktop platforms.

## Scope / Out of scope

In scope: GitHub Actions workflow(s) invoking the same canonical developer/quality interface EP-001 establishes; both macOS and Windows exercised — this requirement comes from Corytm's accepted desktop-first product direction; basic dependency/security checks where a real need is identified during refinement.

Out of scope: deployment, release pipelines, package publishing, installers, signing/notarization, cloud infrastructure — no continuous-delivery capability is in scope, hence "Continuous Integration," not "CI/CD."

## Acceptance criteria

CI runs on every relevant change. CI invokes the identical quality interface a local session uses, with no gate weaker than local. Both macOS and Windows are exercised for build+test of each component.

## Dependencies

EP-001.
