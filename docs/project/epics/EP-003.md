# EP-003 — Harness Validation

Status: ready
Milestone: MS-001

## Objective

Prove — not just construct — that a fresh Claude Code session with no conversation history can execute a real repository Task end-to-end under Corytm's governance, using EP-002's already-established CI evidence that the interface works remotely, without requiring the fresh session itself to trigger CI or administer Git.

## Scope / Out of scope

In scope: select and execute one genuine, useful, non-product repository Task through the full DISCOVER → PLAN → IMPLEMENT → REVIEW → VALIDATE → SYNC → CLOSE protocol; VALIDATE runs the canonical local quality interface EP-001 establishes — CI's own remote proof is EP-002's completed evidence, not something this exercise re-triggers; confirm PMO/status synchronization actually occurs at CLOSE; confirm the session can identify/recommend next work afterward; the session performs no Git staging, commit, push, PR, or merge, consistent with CLAUDE.md's standing git-administration prohibition.

Out of scope: any Alpha/product functionality; a contrived or fake validation Task invented merely to exercise the process; triggering or re-proving CI itself.

## Acceptance criteria

A real Task is executed end-to-end by a fresh session under governance. The canonical local quality interface passes against the resulting change. `status.md` is correctly synchronized at close. The session recommends next work without relying on conversation history. No Git administration occurs during the exercise.
