# EP-010 — Desktop's First Real Domain Command

Status: active
Milestone: MS-002

## Objective

Connect the two mechanisms MS-002's manual-editing Outcome half has depended on since EP-006 and EP-009 respectively — Corytm Engine's proven move-clip operation (EP-006/EP-008) and the proven Desktop↔Python socket channel (EP-009) — into real, running Desktop application code, ending with a human able to trigger one real edit from an actual Tauri window. Mirrors this Milestone's own established shape (EP-004 → EP-005 → EP-006 → EP-009, each proving one mechanism before the next builds on it): this Epic is the first to build a real, if still deliberately minimal, product behavior on top of all of them at once.

## Scope / Out of scope

In scope, as separate increments:

1. Production sidecar spawn/shutdown: the real, shipped Tauri app (not only `cargo test`) spawns the Python core sidecar on startup, completes EP-009's handshake, and shuts it down when the app exits.
2. A real command/event pair traveling over the Desktop channel that exercises Corytm Engine's already-proven `with_clip_moved` + native live-session mechanism (EP-006/EP-008) against an in-memory fixture project — not `DesktopProofMessage` any longer.
3. A minimal, real UI trigger (for example, one button) a human can click to fire that command and see its result.

Out of scope: real project creation, opening, or persistence; any track/clip authoring UI beyond triggering one hardcoded move; multiple concurrent projects or windows; Dorian/provider wiring; any visual/UX design investment beyond function (`docs/product/design.md`'s system remains open for later application).

## Acceptance criteria

A human can launch the real Desktop app, see it spawn and connect to the Python core sidecar over EP-009's channel, click a real UI control, and observe a real Corytm Engine edit (a clip moving) having been applied and re-rendered through the Native Audio Runtime — proven end to end by a combination of automated tests (per-increment, mirroring this Milestone's established practice) and, where real GUI process lifecycle can't be exercised headlessly, a human confirmation step, distinct from and in addition to automated evidence.

## Dependencies

EP-006 (done) — the move-clip mechanism this Epic exposes. EP-009 (done) — the channel this Epic uses for real for the first time.

## Notes

Selected as MS-002's next Epic after EP-009 closed: real Desktop project-creation/editing UI was judged too large a jump before any real domain command exists over the channel, and Dorian-model/provider wiring remains blocked on an explicit, not-yet-made provider-selection decision (`docs/product/strategy.md` §10's protected list). This Epic deliberately reuses `with_clip_moved` unchanged rather than inventing a new operation — the smallest already-proven capability that makes real, observable progress on this Milestone's still-open manual-editing half. No Protected Product Decision (`CLAUDE.md` §5) is implicated: MS-002's own Outcome already requires a user to produce sound via direct manual editing through the real stack, so this Epic formalizes already-agreed behavior rather than introducing new product territory.

Feature/Task-level detail is refined now, at the point this Epic begins execution, per `docs/project/plan.md`'s Rolling-Wave Planning.
