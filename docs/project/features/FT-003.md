# FT-003 — Native Runtime Build Foundation

Status: done
Epic: EP-001

## Objective

Establish a native C++ build/test foundation with Tracktion Engine + JUCE integrated: a CMake-based build system under `src/backend/audio/` that vendors Tracktion Engine and JUCE, builds a minimal target linking against them, and runs at least one passing native test — proving the native toolchain before any production audio behavior exists.

## Acceptance criteria

A native build system exists under `src/backend/audio/` and builds successfully. Tracktion Engine and JUCE are vendored and linked into the build. At least one native test builds and runs successfully. No production audio/DAW behavior (track creation, plugin hosting, playback, transport) is implemented.

## Dependencies

None.

## Notes

Excludes Python↔C++ protocol/schema implementation, any real audio/MIDI/plugin functionality, and cross-platform CI validation (EP-002). RSK-001 (Tracktion Engine + JUCE native build/integration risk) applies directly to this Feature — its mitigation is to keep this Feature's initial proof deliberately minimal.
