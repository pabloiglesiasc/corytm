# FT-004 — Unified Quality Interface

Status: done
Epic: EP-001

## Objective

Establish a single root Makefile-based interface unifying the Python, frontend, and native checks into a canonical Task-level quality gate (`make check`) and a canonical full-repository quality gate (`make check-all`) — the interface `CLAUDE.md`'s Task Execution Protocol already expects. A pre-commit hook is not pursued (explicitly optional, and out of scope for this Feature's minimal proof).

## Acceptance criteria

`make check` runs the Python, frontend, and native checks and passes. `make check-all` performs the same validation from a fully clean state and passes. No component's quality constraint is weakened by the unification. No product/domain functionality is introduced.

## Dependencies

FT-001, FT-002, FT-003.

## Notes

Excludes CI invocation of this interface (EP-002).
