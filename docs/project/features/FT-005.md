# FT-005 — CI Pipeline

Status: done
Epic: EP-002

## Objective

Establish a GitHub Actions workflow that invokes Corytm's canonical quality interface (`make check`) on both macOS and Windows runners for every push and pull request.

## Acceptance criteria

A GitHub Actions workflow exists at `.github/workflows/` and defines a build matrix covering `macos-latest` and `windows-latest`. Each platform's job checks out the repository, provisions the same tools a local session uses (uv, Node, CMake/Ninja, and — on Windows — GNU Make via Chocolatey), and runs `make check`. No gate is weaker than the local `make check` it invokes.

## Dependencies

None (EP-002's own dependency on EP-001 already governs this Feature).

## Notes

Dependency/security scanning (mentioned as a possible addition in EP-002's Scope) is not included — no concrete need has been identified during this refinement, consistent with the "only if a real need is identified" framing in EP-002 itself.
