# FT-009 — Python↔Native Audio Runtime Transport Proof

Status: active
Epic: EP-004
Milestone: MS-002

## Objective

Prove ADR-007's transport — a length-prefixed, protobuf-carrying local loopback socket, authenticated by a per-launch secret before any command traffic is accepted — actually works between a real Python process and a real Native Audio Runtime process, reusing FT-008's already-proven `src/schemas/proof.proto` schema rather than inventing new message content. Mirrors FT-007/FT-008's "prove the toolchain before building on it" pattern for the last unproven piece of ADR-007 (the schema/codegen half is already proven; this proves the wire mechanics and authentication).

## Acceptance criteria

The Python core (acting as the listener, matching ADR-007's Jupyter-kernel-style pattern) generates a random per-launch secret and opens a loopback TCP server on an OS-assigned port; it spawns a new native executable, passing the port and secret as launch arguments. The native process connects back to that port and sends the secret as its first message before any other traffic; Python only proceeds once that secret matches. Python then sends a `ProofMessage` command; the native process receives it, decodes it, and sends a `ProofMessage` event back; Python receives and verifies it. The wire framing matches JUCE's `InterprocessConnection` format exactly (a magic-numbered, length-prefixed header) so the C++ side can use it as-is per ADR-007's own "initial implementation uses JUCE's existing `InterprocessConnection`" language, with the Python side implementing the same framing manually over `asyncio` (no new Python dependency, per ADR-007's "Python uses stdlib asyncio"). This full round trip is exercised by a real, automated test — not just reasoned through — and passes locally and (once pushed) in CI on both macOS and Windows. No sidecar/Tauri process spawning, no real product command/event content, and no persistent connection/reconnection handling — this proves one authenticated round trip, not a production transport layer.

## Dependencies
