# FT-019 — Desktop Schema & Rust Codegen Proof

Status: done
Epic: EP-009
Milestone: MS-002

## Objective

Prove the Rust half of ADR-010's toolchain: a Desktop-facing Protobuf schema, independent of `project.proto`'s native-facing envelope, compiles into real Rust bindings via `prost`/`prost-build`, and a `protoc` executable is obtained safely (SHA256-verified against the same official, already-pinned release CMake uses) without depending on `check-native`'s build order or an unverified third-party downloader. Mirrors FT-008/TK-009's C++/Python codegen proof exactly, one toolchain later.

## Acceptance criteria

A new schema file under `src/schemas/` (distinct from `project.proto`) defines one illustrative proof message, mirroring `proof.proto`'s own role for the C++/Python side. `src-tauri/build.rs` obtains a `protoc` executable by downloading and SHA256-verifying the same official release CMake already pins (no reuse of CMake's own downloaded artifact — `check-desktop` must remain buildable independent of whether `check-native` has run), then generates Rust bindings via `prost-build` into `OUT_DIR`. A `cargo test` constructs the proof message, encodes it, decodes it, and asserts equality — proving the codegen pipeline end to end, with zero new compiler warnings. `make check-desktop` passes locally with the new toolchain wired in. No Python or C++ schema/codegen code changes; no socket/transport code yet (deferred to a later Feature).

## Dependencies

ADR-010 (accepted) — the architecture this Feature's toolchain half realizes.
