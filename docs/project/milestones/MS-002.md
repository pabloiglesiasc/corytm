# MS-002 — First Sound

Status: active

## Outcome

A user can create or open a Corytm project and produce actual sound through the full real stack via direct manual editing (user → desktop → Python core → Corytm Engine → Runtime → Native Audio Runtime → Tracktion Engine → sound), and Dorian can perform a real semantic edit through the same governed application path with an observable effect on that sound (user → Dorian → Corytm Engine → Runtime → sound) — Alpha's two end-to-end product paths (`docs/project/plan.md`), both real and demonstrable.

## Notes

Was `planned`, not `active`, until the two foundational architecture boundaries both product paths depend on were resolved: the desktop shell technology (ADR-006 — Tauri 2) and the Python↔C++ transport (ADR-007 — Protobuf over a local loopback-socket transport), both decided with explicit user approval under `CLAUDE.md` §5. EP-004, this Milestone's first Epic, is done (see `docs/project/status.md`): both ADRs are proven working in practice via minimal plumbing (Tauri shell, schema/codegen, transport, sidecar spawn/shutdown).

EP-005 (First Sound: Minimal Track and Clip Through Tracktion), this Milestone's second Epic, is implemented and locally verified end to end on the user's explicitly approved scope: a real Python entry point owning a minimal `Project`/`AudioTrack`/`AudioClip` crosses the ADR-007 transport, and the Native Audio Runtime genuinely materializes it as a real Tracktion `Edit` and renders real, deterministic, non-silent sound — offline, with no audio device, plus a real playable WAV file confirmed produced. It stays `active`, not `done`, pending real Windows CI confirmation (`CLAUDE.md` §10 — this session cannot push) and the human-only local audible smoke test EP-005's own scope calls for as a distinct acceptance boundary.

This Milestone's Outcome is still not fully reached even once EP-005 closes: EP-005 deliberately proves only a synthetic-fixture, one-track/one-clip slice driven by a hardcoded script, not a real user-facing project-creation flow, real imported audio, or Dorian's semantic-edit path. The Epic after EP-005 — genuinely reaching this Outcome — is a further product-scope decision, not yet made.
