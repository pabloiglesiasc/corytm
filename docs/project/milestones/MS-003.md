# MS-003 — Live Playback

Status: active

## Outcome

A user can press Play on a real Corytm project in Desktop and hear it through genuine real-time audio-device output — with live transport control (play/stop) and a moving playhead reflecting real-time position — not merely produce an offline-rendered file the way every prior Milestone's work has. This directly satisfies `docs/project/plan.md`'s Alpha Exit criteria condition that "real-time audio is demonstrated, not merely offline rendering" (`docs/product/roadmap/alpha.md`'s Real-Time Audio & Transport category, which states this outright: "Real-time playback/device output is an Alpha blocker: offline rendering (already proven) does not by itself satisfy this category").

## Notes

Created following `docs/project/status.md`'s own recommendation, left open by the prior session's product-governance consolidation: with MS-002 (First Sound) achieved but Alpha's own exit criteria found genuinely broader than MS-002's Outcome ever claimed, real-time audio-device playback was identified as the most evidently unmet, highest-leverage capability `docs/product/roadmap/alpha.md` still names — every product path proven so far (EP-005 through EP-013) renders offline to a WAV file; nothing in the Native Audio Runtime has ever opened a real audio device or driven live playback.

Scoped narrowly, mirroring MS-002's own discipline of proving one transversal outcome rather than absorbing all remaining Alpha scope at once: this Milestone is real-time playback specifically (`docs/product/roadmap/alpha.md`'s "Real-time audio-device initialization/output," "Live play/stop/pause transport," "Playhead and real-time position," "Transport state reflected coherently in UI"). Seek/arbitrary positioning, loop-region playback, metronome/count-in, sample-rate/buffer configuration, device input/output configuration, hot-plug/recovery, master output monitoring/metering, and clipping indication are the same roadmap category's remaining entries and are deliberately left for later Milestone/Epic work, not folded in here.

**EP-014 (Real-Time Playback Foundation)** was created as this Milestone's first Epic.
