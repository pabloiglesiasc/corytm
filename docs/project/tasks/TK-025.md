# TK-025 — Corytm Engine Persistence Module

Status: done
Feature: FT-023
Milestone: MS-002

## Objective

Implement ADR-011's local JSON persistence format as a real, isolated `corytm.engine.persistence` module: `save_project`/`load_project`, with no protocol, channel, or UI change — the foundation FT-023's Desktop channel work builds on next.

## Scope / Out of scope

In scope:

- `src/backend/core/src/corytm/engine/persistence.py` (new): `SCHEMA_VERSION` (starting at `1`); `save_project(project: Project, path: Path) -> None` writing `{"schema_version": SCHEMA_VERSION, "project": project.model_dump(mode="json")}` as JSON to `path`; `load_project(path: Path) -> Project` reading that envelope back and reconstructing a `Project` via `Project.model_validate`.
- A typed `ProjectFileError` (a `ValueError` subclass) raised by `load_project` when: the file's content isn't valid JSON; the parsed content isn't an object carrying both `schema_version` and `project` keys; or `schema_version` doesn't equal the module's current `SCHEMA_VERSION` — each checked, and raised, before `Project.model_validate` is ever called.
- Colocated tests (`src/backend/core/src/corytm/engine/test_persistence.py`, matching this package's existing colocated-test convention).

Out of scope: any `project.proto`/Desktop-channel/Rust change (TK-026); any project-bundle/directory format or external resource reference; any migration or backward-compatibility mechanism between schema versions (ADR-011 explicitly defers this).

## Acceptance criteria

- `save_project` then `load_project` round-trips a `Project` with multiple tracks and clips unchanged (`==` equality, since `Project` is a frozen Pydantic model).
- `load_project` raises `ProjectFileError` for: a file containing invalid JSON; a file containing valid JSON that is missing `schema_version` or `project`; a file whose `schema_version` doesn't match `SCHEMA_VERSION` — in every case, without constructing a `Project`.
- `make check-python` passes (`pytest -m "not transport"`, `pyright` strict, `ruff check`/`ruff format --check`).

## Dependencies

None beyond `corytm.engine.project` (already done).

## References

`decisions/ADR-011.md` (the exact envelope shape and its "current implementation mechanism, not itself the permanent contract" framing); `src/backend/core/src/corytm/engine/project.py`/`track.py`/`clip.py` (the models being persisted); `docs/technical/architecture.md`'s "Local Project Persistence" section.
