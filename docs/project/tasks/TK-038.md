## Acceptance criteria

- Each skill's frontmatter has only a `description` field, matching `ui-ux-review`/`testing-review`'s own shape; each opens with a ground-truth pointer to the canonical document(s) that actually govern its domain (no new canonical doc is created for any of the four — the review found each already has one).
- `state-reconciliation`: ground truth is `CLAUDE.md` §6 (post-TK-037 wording) and `docs/project/format.md`'s State Transitions/Evidence Traceability. States evidence-first semantics explicitly (establish what is actually true before updating any PMO/status summary) and names the fast path in its own Output: when an Active Feature has safe, executable work remaining, the verdict is "continue directly," not a recommendation to run `next-work-selection`.
- `next-work-selection`: ground truth is `docs/project/plan.md`'s Next-Work Selection Priority and Rolling-Wave Planning sections, plus `CLAUDE.md` §5/§6 (post-TK-037). Uses qualitative, evidence-cited comparison only — no numerical or weighted scoring anywhere in the file. Carries the dependency-safety-check procedure relocated from `CLAUDE.md` §6 largely verbatim: the Risk-naming-a-surface-is-evidence-not-a-verdict distinction, the plausible-invalidation-vs-proximity judgment with its worked examples, the `RSK-002`–`RSK-015` precedent, the infrastructure-only-failure exemption, and the retroactive pause-and-reconcile instruction for a concurrently Active Feature.
- `lifecycle-review`: ground truth is `docs/project/plan.md`'s Lifecycle Model and Current Phase sections. States its trigger narrowly: invoked when a lifecycle-phase transition is being recommended, or a Milestone's outcome is being cited as evidence for one — explicitly not during ordinary Milestone close-out where phase exit isn't implicated. Names the three checks from the real MS-002/Alpha incident: Milestone-achieved ≠ lifecycle-complete; a literal evidence checkbox ≠ the semantic phase promise; roadmap-capability-completion ≠ the phase's own qualitative exit gate.
- `harness-review`: ground truth is `CLAUDE.md` §4 (source-of-truth order) and §11 (Knowledge & Harness Governance). States its trigger (explicit request, or opportunistic only on concrete evidence already surfaced — never by default on Continue Corytm) and its proportional-delegation rule (a narrow, localized contradiction is inspected directly; a broad cross-artifact audit may delegate its read-heavy discovery to the existing general-purpose/Explore agent mechanism, introducing no new agent type). States explicitly that it may only propose governance/structural changes, never apply them silently.
- No skill restates another canonical document's durable content (four-tier testing policy, roadmap mutation rules, PMO format) — each stays inside its own declared domain.
